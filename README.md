# 多端资金盘金融系统

一个面向海外业务场景打造的多端金融系统项目，基于 `Go + GoFrame v2 + Vue 3 + uni-app` 技术栈构建，覆盖后端 API、运营管理后台与移动端用户应用三端体系，围绕用户账户、资金链路、订单收益、团队关系、权限管理与经营分析形成完整业务闭环。

这是是一套具系统完整度、工程组织能力与二次开发价值的综合型业务平台。

适配资金盘,海外基金盘,自带推广模型,裂变模式,已服务数十家海外资金盘项目,可靠稳定,7*24小时维护

## 项目亮点

### 三端一体化，天然具备完整业务闭环

项目由三部分构成：

- `backend`：Go 后端 API 服务
- `midground`：Vue 3 运营管理后台
- `uniapp`：H5 / App / 小程序多端用户应用

这种架构使项目同时具备用户端承载能力、后台运营能力和后端业务处理能力，能够更完整地表达真实业务系统的结构，而不是局限于某一个局部模块。

### 多端统一交付，覆盖更多业务入口

移动端基于 `uni-app + Vue 3 + TypeScript` 构建，一套代码可输出到：

- H5
- App
- WhatsApp小程序
- Telegram小程序

对于需要多渠道触达用户的业务来说，这种多端统一方案能够显著降低重复开发成本，也更利于后续统一维护与持续迭代。

### 业务链路完整，功能模块覆盖全面

项目当前已经具备较完整的核心能力，包括：

- 用户注册、登录、退出、信息维护
- 密码管理、提现密码管理
- 钱包地址接入与钱包签名登录扩展能力
- 充值订单创建、充值通道获取、充值异步回调处理
- 提现申请、提现配置、账变记录与资金状态跟踪
- 订单管理、收益统计、返佣相关字段建模
- 团队关系、代际成员、团队统计与层级能力
- 后台用户、角色、菜单、按钮权限管理
- 用户统计、资金统计、日统计与经营分析能力
- 多端多渠道SASS体系, 可开通经理/组长/业务员 分权限管理用户数据


### 后台运营能力成熟，适合持续管理

中后台不仅具备基础登录能力，还已经形成较完整的运营管理体系，包括用户管理、角色管理、菜单管理、权限控制和数据边界隔离等能力。对于需要多人协作、角色分工和长期运营的系统来说，这类后台能力是非常重要的核心支撑。

### 团队关系与层级体系明确

从用户结构、团队接口、统计能力和管理范围控制来看，项目对团队关系、层级管理和组织型业务场景有较明确的建模基础。这使系统不仅能处理用户和订单，还能进一步承接团队协作、分层运营和组织管理相关需求。

### 工程结构清晰，适合长期二开

- 后端具备 API / Service / Model / DAO 清晰分层
- 中后台采用 Monorepo 与共享包模式组织能力
- 移动端统一封装路由、状态、请求和 UI 组件体系
- 前后台均具备国际化基础能力
- 权限体系采用 JWT + RBAC 统一控制

这让项目更适合作为长期维护和持续演进的业务底座。

### 架构特点

- 前台、后台、开放接口按业务域拆分，接口边界清晰
- 用户端和管理端分别面向不同角色，避免职责混杂
- 后端统一承接鉴权、权限、业务规则、资金状态和数据统计
- 数据层围绕用户、订单、资金、团队、权限等核心模型组织
- 多端应用、后台系统和后端服务可以独立迭代，也可以协同交付

## 工程优势

### 清晰分层，便于维护

后端采用明确的接口层、服务层、模型层、DAO 层划分；中后台与移动端在路由、请求、状态、组件等方面也有较统一的组织方式，整体结构清晰，便于快速定位问题和持续开发。

### 权限体系完善，适合复杂业务场景

项目结合 JWT 鉴权、RBAC 角色权限、菜单控制、按钮权限和数据边界管理，能够更好地支撑多角色协同和后台运营控制。

### 国际化基础具备，适合面向海外扩展

前后台均具备国际化支持能力，为多语言、多地区场景预留了较好的扩展路径，也更适合海外业务方向的持续演进。

### 多端与工程化兼顾

项目不仅关注业务实现，也关注工程落地，具备 Docker / Kubernetes 方向部署基础，同时在移动端、多端编译和前端工程组织上也具备较高完整度。

- 具备后台运营、权限控制、数据分析需求的项目
